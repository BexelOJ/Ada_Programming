ADA DS

LEARNING ROADMAP · 7 PHASES

--------------------
1. Phase 01:
   
   Fundamentals
   
   Arrays, records, access types, enumeration, 
   strings and unconstrained arrays

--------------------
2. Phase 02:

   Dynamic arrays, linked lists, 
   stacks, queues and deques

--------------------
3. Phase 03:
   
   Associative Data Structures
   
   Hash tables, maps, sets and 
   ordered collections

--------------------
4. Phase 04:
   
   Trees
   
   Binary trees, BST, AVL, Red-Black trees, 
   heaps, tries and B-trees

--------------------
5. Phase 05:
   
   Graphs
   
   Graph representations, traversal, 
   shortest paths and spanning trees

--------------------
6. Phase 06:
	
   Advanced Data Structures
   
   Disjoint sets, Fenwick trees, segment trees, 
   Bloom filters and LRU caches

--------------------
7. Phase 07:

   Concurrent Data Structures
   
   Protected objects, synchronized queues and 
   concurrent access

Ada standard library comparison
One important part of this roadmap is learning 
Ada's standard Ada.Containers packages 
after implementing the underlying concepts manually.

Your implementation	Ada standard package
Dynamic Array - Ada.Containers.Vectors
Bounded Array - Ada.Containers.Bounded_Vectors
Doubly Linked List - Ada.Containers.Doubly_Linked_Lists
Hash Map - Ada.Containers.Hashed_Maps
Ordered Map - Ada.Containers.Ordered_Maps
Hash Set - Ada.Containers.Hashed_Sets
Ordered Set - Ada.Containers.Ordered_Sets
Multiway Tree - Ada.Containers.Multiway_Trees

Recommended implementation format:

1. Concept: 
   What is the data structure?

2. Internal representation: 
   How is memory organized?

3. Operations: 
   Insert, delete, search, traverse, update.

4. Complexity: 
   Time and space complexity.

5. C comparison: 
   How would you implement it in C?

6. Rust comparison: 
   How does Rust handle ownership and memory?

7. Ada implementation: 
   Write a standalone Ada program.

8. Generic implementation: 
   Where appropriate, implement using Ada generics.

9. Testing: 
   Test cases, boundary conditions and expected output.

10. Standard library: 
    Compare with Ada.Containers.

My recommendation
Follow this order:

First:
Implement the data structures manually using Ada

Second:
Understand generic programming and memory management

Third:
Compare your implementation with Ada.Containers

Fourth:
Write test programs for 
insertion, deletion, searching, edge cases 
and memory handling.

This way, you learn both Ada programming and the 
underlying data-structure engineering rather than 
simply learning how to call library functions
